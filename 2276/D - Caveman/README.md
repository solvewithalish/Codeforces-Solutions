He wants to color each vertex red or blue so that every vertex has at least one neighbor of the opposite color. He needs to calculate the number of colorings that suit him.</p><p>Monocarp is a caveman: he knows only the numbers $$$1$$$, $$$2$$$, and "many" (any number greater than $$$2$$$). He does not know about zero, so if there are no valid colorings, his brain melts.</p><p>Help Monocarp count the valid colorings in his language. Two colorings are considered different if at least one vertex has a different color in them.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains an integer $$$t$$$ ($$$1 \le t \le 10^4$$$) — the number of test cases.</p><p>The first line of each test case contains two integers $$$n$$$ and $$$m$$$ ($$$3 \le n \le 3 \cdot 10^5$$$; $$$0 \le m \le \min\left(\frac{n(n-1)}{2}, 3 \cdot 10^5\right)$$$) — the number of vertices and edges.</p><p>Each of the next $$$m$$$ lines contains two integers $$$u_i$$$ and $$$v_i$$$ ($$$1 \le u_i, v_i \le n$$$) — the numbers of the vertices connected by the $$$i$$$-th edge. The graph has no self-loops or multiple edges.</p><p>Additional constraints on the input:</p><ul> <li> the sum of $$$n$$$ over all test cases does not exceed $$$3 \cdot 10^5$$$; also the sum of $$$m$$$ over all test cases does not exceed $$$3 \cdot 10^5$$$. </li></ul></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print on a separate class="tex-font-style-tt">Many</span>, if the number of valid colorings is greater than two; </li><li> <span class="tex-font-style-tt">Brain Melt</span>, if there are no valid colorings.
