## Problem Statement

<div class="header"><div class="title">G. Elimination of Players</div><div class="time-limit"><div class="property-title">time limit per test</div>4 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>512 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>In a certain game, there are $$$n$$$ players numbered from $$$1$$$ to $$$n$$$. Each player has a strength — an integer from $$$1$$$ to $$$n$$$. All players have distinct strengths. The distribution of strengths is given by a permutation $$$(s_1, s_2, \ldots, s_n)$$$, where $$$s_j$$$ is the strength of player $$$j$$$.</p><p>Initially, all players take part in the game. The game consists of $$$n-1$$$ rounds. In the $$$i$$$-th round, the player $$$a_i$$$ is <span class="tex-font-style-it">protected</span>. It is possible that the protected player was already eliminated.</p><p>In each round, exactly one player is eliminated. This player is chosen as follows:</p><ul> <li> if the player with the minimum strength among the remaining players is not protected, that player is eliminated; </li><li> otherwise, the player with the second minimum strength among the remaining players is eliminated. </li></ul><p>An eliminated player no longer takes part in the game. After the last round, exactly one player remains.</p><p>You are given the sequence $$$a_1, a_2, \ldots, a_{n-1}$$$, but the distribution of strengths is unknown. For each player $$$j$$$ and each round $$$i$$$, find the number of permutations $$$(s_1, s_2, \ldots, s_n)$$$ for which the player $$$j$$$ is eliminated in the $$$i$$$-th round.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains one integer $$$t$$$ ($$$1 \le t \le 2500$$$) — the number of test cases.</p><p>Each test case consists of two lines:</p><ul> <li> the first line contains one integer $$$n$$$ ($$$2 \le n \le 5000$$$) — the number of players; </li><li> the second line contains $$$n-1$$$ integers $$$a_1, a_2, \ldots, a_{n-1}$$$ ($$$1 \le a_i \le n$$$) — the numbers of the protected players in the corresponding rounds. The values $$$a_i$$$ may repeat. </li></ul><p>Additional constraints on the input:</p><ul> <li> the sum of $$$n$$$ over all test cases does not exceed $$$5000$$$. </li></ul></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print the answer in the following way:</p><p>Let $$$ans(i,j)$$$ denote the number of permutations $$$(s_1, s_2, \ldots, s_n)$$$ for which player $$$i$$$ is eliminated in round $$$j$$$, taken modulo $$$998\,244\,353$$$. Print one integer equal to $$$\oplus_{i=1}^{n} \oplus_{j=1}^{n-1} (ans(i,j)\cdot i\cdot j)$$$, where $$$\oplus$$$ denotes the bitwise exclusive OR (XOR) operation. Only the values $$$ans(i,j)$$$ are taken modulo $$$998\,244\,353$$$; the products $$$ans(i,j)\cdot i\cdot j$$$ and the final answer are not.</p></div><div class="sample-tests"><div
