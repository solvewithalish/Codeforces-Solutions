## Problem Statement

A substring $$$s_{l \dots r}$$$ is bad if it contains the string $$$2025$$$ as a subsequence and <span class="tex-font-style-bf">doesn't</span> contain the string $$$2026$$$ as a subsequence. Otherwise, the substring is good. For example, the strings $$$2025$$$, $$$72707275$$$, $$$20625$$$ are bad, but the strings $$$20256$$$, $$$2026$$$, $$$777$$$, $$$1290723576$$$ are good.</p><p>For each index $$$i$$$ from $$$1$$$ to $$$n$$$, calculate the number of good substrings that contain it. In other words, for each index $$$i$$$ from $$$1$$$ to $$$n$$$, calculate the number of pairs of integers $$$l, r$$$ such that $$$1 \le l \le i \le r \le n$$$ and the substring $$$s_{l \dots r}$$$ is good.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains a single integer $$$t$$$ ($$$1 \le t \le 10^4$$$) — the number of test cases.</p><p>The first line of each test case contains a single integer $$$n$$$ ($$$1 \le n \le 3 \cdot 10^5$$$).</p><p>The second line contains a string $$$s$$$ of length $$$n$$$, consisting of digits.</p><p>Additional constraint on the input: the sum of $$$n$$$ across all test cases does not exceed $$$3 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print $$$n$$$ integers.
